# Efecto Dominó

Proyecto para la **Hackatón Señales** de Makana (Santiago de Chile, 23 y 24 de octubre de 2026) · Caso 01: **Camila**.

App nativa para iPhone (SwiftUI) que trata el regreso al ejercicio como una obra con carta Gantt: cuando la vida cambia, el plan se reprograma sin demoler lo construido.

> En construcción durante el evento. Todos los datos son ficticios.
